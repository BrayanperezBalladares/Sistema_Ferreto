# Professor PHP + Bulma + HTMX Proof of Concept

This directory contains the CRUD proof of concept supplied by the professor.

Purpose:
- Demonstrate PHP + HTMX partial HTML interactions.
- Demonstrate Bulma-based presentation.
- Serve as technical reference for the project.

This code is NOT the production application architecture.

Do not assume:
- its directory structure is mandatory;
- its routing approach is final;
- its database access is production-ready;
- its security model is complete;
- its code should be copied directly into the production application.

The production architecture must be defined through SDD.
